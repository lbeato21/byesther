Un portal de enlaces (Link-in-bio) de alto rendimiento y diseño exclusivo, construido para **Esther Crafts**. Optimizado específicamente para ser escaneado vía código QR en bazares físicos y tiendas, ofreciendo una experiencia móvil fluida e inmediata.

🔗 **Live Demo:** [social.esthercrafts.com](https://social.esthercrafts.com)

---

## 🚀 Características Principales

* **⚡ Rendimiento Extremo:** Construido con Astro. Envía 0 JavaScript al cliente por defecto, garantizando tiempos de carga inferiores a 1 segundo incluso en redes móviles 3G/4G.
* **🎨 Deep Glassmorphism UI:** Diseño moderno con fondos animados (orbs), desenfoques profundos (`backdrop-blur`) y bordes semitransparentes.
* **✨ Neon Tactile Feedback:** Botones tipo píldora que reaccionan al toque (`:active`) con resplandores de neón específicos para cada marca (Rosa para Web, Púrpura para Instagram, Verde para WhatsApp).
* **📱 Mobile-First Real:** Arquitectura CSS diseñada nativamente para pantallas táctiles de smartphones, eliminando el *flash* de toque nativo de los navegadores móviles.
* **🔗 Multi-Marca:** Centraliza el ecosistema de Esther Crafts, integrando:
  * Catálogo Principal (Web)
  * @esther_crafts (Arte y Resina)
  * @esthershopbyec (Accesorios)
  * @floresbyesther (Arreglos Florales)
  * Canal de venta directa (WhatsApp)
